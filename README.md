# Dissident Finance

Dissident Finance is an application where users create, own, and monetize AI agents that execute personalized yield optimization strategies—treating this investment logic as programmable, shareable, and monetizable IP. Unlike traditional robo-advisors or agent marketplaces, users retain full control over both the agent and the yield strategy, enabling a new model of personalized, user-controlled wealth creation. Dissident turns DeFi investing into a creator-owned experience, where automation, ownership, and returns belong to the user.
